# ClickRush - 60-Second Click Challenge

## Overview
Build a full-stack web game where users click as many times as possible within 60 seconds.

The goal is to keep the game simple while testing frontend, backend, database design, APIs, authentication, and engineering thinking.

## Core Features
1. **User Authentication:** Signup and Login functionality.
2. **Game Mechanics:** A 60-second click game.
3. **Score Calculation:** Calculate and store the user's score based on clicks.
4. **Leaderboards:** Global, daily, and weekly leaderboards.
5. **User Profile:** Game history and rankings for the logged-in user.
6. **Backend & Database:** Backend API + database to manage users, scores, and leaderboards.

## Bonus Requirements (Optional but recommended)
- Real-time leaderboard updates.
- Multiple game modes.
- Engaging UI animations.

## Technology Stack
- **Frontend:** Choose an appropriate framework or use plain HTML/CSS/JS.
- **Backend:** Choose a suitable backend language and framework.
- **Database:** Choose an appropriate database for the application.

## Submission Guidelines
- Provide a link to your public GitHub repository containing the source code.
- Ensure your repository includes a `README.md` with:
  - Instructions on how to set up and run the project locally.
  - A brief explanation of your database schema and API endpoints.
- Provide a link to a deployed version of your application.
- Attach a demo video showcasing the functionality of your application (Loom is recommended).

## Evaluation Criteria
- **Functionality:** Does the game work as expected? Are all core features implemented?
- **Code Quality:** Is the code clean, modular, and well-documented?
- **System Design:** Are the database schema and APIs well-designed and efficient?
- **User Experience (UX):** Is the game responsive, intuitive, and visually appealing?
